# 你的 AstrBot 追番小助手

新番列表插件：本周连载番剧的节目单与缩略图网格，支持季度新番表与番剧详情卡片。

数据来源：yuc.wiki（中文新番表、档期）+ AniList（首播/完结日期、集数、封面、简介）。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/list` | 本周连载节目单（按星期分行，含长篇/年番区块） |
| `/list 2026秋` | 该季度新番节目单，也支持 `202610`、`202603` 这类写法 |
| `/listpic` | 本周连载缩略图网格，带封面 |
| `/listpic 2026秋` | 该季度缩略图网格 |
| `/listpic 番剧名` | 番剧详情卡片 |

番剧名支持模糊匹配，取相似度最高的一条；默认返回第一季，写 `第2季`、`2期`、`2`、`s2` 可指定季数。

## 番名检索流程

查一部番时按下面的顺序走，越靠前越快：

1. **本地索引** `yuc_index.json`（1479 条，覆盖 2019 秋 - 2026 全年）：三级匹配——完全相等 → 以关键词开头取最短 → 包含关键词取最短 → 相似度兜底（阈值 0.85）。命中后直接拿到日文名，完全不需要联网。
2. **在线抓取**：索引未命中时，抓当季页与上季页，按 `M/D周X` 解析作品与档期，再用相似度打分。
3. **手工别名表** `cn_alias.json`：给 yuc 没写日文名的长篇/年番，以及索引覆盖不到的往年番兜底。
4. **AniList 查询**：拿到日文名后查详情（封面、集数、首播/完结、状态、制作公司）。

## 关于 2019 秋之前的番剧

**yuc.wiki 从 2019 年秋才开始建站**，2013 - 2018 全年、以及 2019 年的冬/春/夏三个季页都是 404。因此：

- 索引 `yuc_index.json` 最早只到 `201910`，之前的番天然不可能被收录
- 这些番拿不到中文名对日文名的映射，也拿不到档期信息

### 搜索兜底（可配置）

插件内置一条兜底链路，可以在配置里填入搜索服务的 API Key 来启用：

| 配置项 | 说明 |
| --- | --- |
| `tavily_api_key` | Tavily API Key。**留空即关闭兜底**，填写后生效 |
| `tavily_max_results` | 每次搜索取几条结果来提取日文名，默认 5 |

启用后的完整流程：

1. 本地索引、别名表、AniList 直搜全部落空
2. 调用 Tavily 搜索「中文名 动画 日文原名」
3. 从维基百科、Bangumi、萌娘百科等结果里提取官方日文名
4. 拿日文名去 AniList 逐个验证，确认年份与集数对得上
5. 命中后自动写回 `cn_alias.json`，**以后这条永久有效，不再联网**

示例：查「天使降临到我身边」时，搜索会从维基结果里取到「私に天使が舞い降りた！」，验证通过后写进别名表。

注意：**不要用机器翻译把中文直译成日文**。官方番名往往不是直译（「天使降临到我身边」直译会变成「天使が私のそばに降りてくる」，与官方名「私に天使が舞い降りた！」差异极大），翻译结果在 AniList 里基本搜不到。

不配置 Key 也完全可用，只是 2019 秋之前的老番会提示「没找到」，其余功能不受影响。

## 特性

- 三档字色判定：先按文字实际落点取 9 条横带，上下落差超过 70 用淡蓝字加白描边；落差不大再看中位数分亮/中/暗三档
- 连载中的番每次重新渲染保证时效，已完结的复用缓存不重渲染；缩略图网格每次重新渲染
- AniList 请求串行并带退避，避免限流；失败不会写入空缓存
- 长篇/年番区块在 yuc 没有日文名，用 `cn_alias.json` 补

## 安装

把本仓库放进 AstrBot 的 `data/plugins/` 目录，重载插件即可。

依赖：`aiohttp`、`beautifulsoup4`、`Pillow`，AstrBot 环境通常已经自带。

## 配置

`cn_alias.json` 是中文到日文的番名映射，给两种场景兜底：

- yuc 有页面但没写日文名的长篇/年番
- yuc 建站之前（2019 秋以前）的往年番

格式：

```json
{
  "名侦探光之美少女": "名探偵プリキュア！",
  "平凡职业造就世界最强": "ありふれた職業で世界最強",
  "天使降临到我身边": "私に天使が舞い降りた！"
}
```

只需要写基础名一条，`平凡职业造就世界最强2`、`…3` 这种会自动按季数推导。

`yuc_index.json` 是从 yuc.wiki 抓取生成的全量中日索引，随仓库一起分发，不需要手动维护。

## 目录结构

```
main.py              指令入口与流程编排
render.py            番剧详情卡片渲染
render_list.py       节目单渲染
render_grid.py       缩略图网格渲染
sources/yuc.py       yuc.wiki 解析
sources/anilist.py   AniList GraphQL 查询
sources/covers.py    封面地址批量获取（串行 + 缓存）
sources/image_cache.py 图片磁盘缓存
yuc_index.json       2019 秋 - 2026 全量中日番名索引
cn_alias.json        中文到日文番名映射（手工补充）
```
