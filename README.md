# 你的 AstrBot 追番小助手

新番列表插件：本周连载番剧的节目单与缩略图网格，支持季度新番表与番剧详情卡片。

数据来源：yuc.wiki（中文新番表、档期）+ AniList（首播/完结日期、集数、封面、简介），2019 秋之前的老番可借助搜索服务补全。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/list` | 本周连载节目单（按星期分行，含长篇/年番区块） |
| `/list 2026秋` | 该季度新番节目单，也支持 `202610`、`202603` 这类写法 |
| `/listpic` | 本周连载缩略图网格，带封面 |
| `/listpic 2026秋` | 该季度缩略图网格 |
| `/listpic 番剧名` | 番剧详情卡片 |

## 番名检索

按三步走，越靠前越快：

1. **本地索引** `yuc_index.json`（1474 条，覆盖 2019 秋 - 2026 全年）：完全相等 → 以关键词开头取最短 → 包含关键词取最短 → 相似度兜底（阈值 0.85）。命中后直接拿到中文名和日文名，不联网。简称省略「的」「之」这类虚词也能匹配。
2. **AniList 直接搜**：不少老番的 synonyms 里存有中文译名，直接搜就能命中。
3. **Tavily 搜萌娘百科**：前两步都落空才启用，先只搜萌娘百科，再放宽到 Bangumi、维基，最后不限域名。结果必须真的提到用户输入的名字，否则一律不认，避免假番名乱配。

全部落空才回「没找到」。

## 季数规则

- 默认取第一季。命中续作（如「夏目友人帐 漆」）会自动回落第一季。
- 写 `第2季`、`2期`、`2`、`s2` 可指定季数；`第N期` 里的旧字形（弐参肆伍陸漆捌玖）以及日文「～そのに～」「Ⅱ」「Ⅲ」也能识别。
- **指定哪一季就只查哪一季，该季不存在就不出图**，绝不拿别的季凑数。
- 卡片标题 = 规范中文名 + 期数（如「侦探已死 第2期」），期数取最终查到的那一部。

## 特性

- 三档字色判定：按文字实际落点取 9 条横带，上下落差超过 70 用淡蓝字加白描边；落差不大再看中位数分亮/中/暗三档
- 连载中的番每次重新渲染保证时效，已完结的复用缓存不重渲染；缩略图网格每次重新渲染
- 渲染结果、封面图片、常用译名三层缓存，同一部不会重复请求
- AniList 请求串行并带退避，失败不会写入空缓存
- yuc 用 `title_cn_r` / `title_jp_r` 区分中英日文名，旧版页面按字符特征分组兜底

## 关于 2019 秋之前的番剧

**yuc.wiki 从 2019 年秋才开始建站**，2013 - 2018 全年、以及 2019 年的冬/春/夏三个季页都是 404。这些番既进不了索引，也拿不到档期。

### 搜索兜底（可配置）

| 配置项 | 说明 |
| --- | --- |
| `tavily_api_key` | Tavily API Key。**留空即关闭兜底**，填写后生效 |
| `tavily_max_results` | 每次搜索取几条结果来提取日文名，默认 5 |

启用后：搜「中文名 动画 日文原名」→ 从维基百科、Bangumi、萌娘百科提取官方日文名 → 拿去 AniList 逐个验证 → 命中后自动写回 `cn_alias.json`，以后永久有效。同时会顺手记下常用译名，供卡片标题使用。

注意：**不要用机器翻译把中文直译成日文**。官方番名往往不是直译（「天使降临到我身边」直译是「天使が私のそばに降りてくる」，官方是「私に天使が舞い降りた！」），翻译结果在 AniList 里基本搜不到。

不配置 Key 也完全可用，只是老番会提示「没找到」。

## 安装

把本仓库放进 AstrBot 的 `data/plugins/` 目录，重载插件即可。

依赖：`aiohttp`、`beautifulsoup4`、`Pillow`，AstrBot 环境通常已经自带。

## 配置

`cn_alias.json` 是中文到日文的番名映射，给两种场景兜底：

- yuc 有页面但没写日文名的长篇/年番
- yuc 建站之前（2019 秋以前）的往年番

```json
{
  "名侦探光之美少女": "名探偵プリキュア！",
  "平凡职业造就世界最强": "ありふれた職業で世界最強",
  "天使降临到我身边": "私に天使が舞い降りた！"
}
```

只需要写基础名一条，`平凡职业造就世界最强2`、`…3` 会自动按季数推导。

`yuc_index.json` 是从 yuc.wiki 抓取生成的全量中日索引，随仓库分发，不需要手动维护。

## 目录结构

```
main.py              指令入口与流程编排
render.py            番剧详情卡片渲染
render_list.py       节目单渲染
render_grid.py       缩略图网格渲染
sources/yuc.py       yuc.wiki 解析
sources/anilist.py   AniList GraphQL 查询
sources/covers.py    封面地址批量获取（串行 + 缓存）
sources/tavily.py    搜索兜底与日文名、译名提取
sources/image_cache.py 图片磁盘缓存
yuc_index.json       2019 秋 - 2026 全量中日番名索引
cn_alias.json        中文到日文番名映射（手工补充）
```
